# Smoke test for the preview deployment

Run on the **preview** address (database `voter-list-preview`), once on a phone and once on a laptop, with real e-mail IDs you control (the Cloudflare Email Service secrets must be set on the preview project). Use made-up society and people names. While you click, keep the Pages Function logs open (Cloudflare dashboard, Pages, voter-list, Functions, real-time logs) and look for `Exceeded CPU` or `Error 1102`.

Pass means all nineteen rows (1 to 17, 23 and 24, on the preview) behave as written and the log shows no CPU or 5xx errors. Rows 18 to 22 are done once, at the address go, and must also pass before the address is shown to anyone. Write the result, the time and the browser in `docs/PROGRESS.md`. If row 4, 9 or 10 hits the CPU limit, stop and use the fallbacks in the README (do not turn on anything paid without the owner).
